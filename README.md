Crop Yield Prediction System

Description

This project predicts crop yield using Machine Learning. It uses different models to analyze data and give accurate predictions.

Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

Models Used

* Linear Regression
* Decision Tree
* Random Forest

Features

* Data preprocessing
* Model training
* Prediction
* Graph visualization

🚀 How to Run the Project
Step 1: Install Required Libraries
pip install pandas numpy matplotlib scikit-learn streamlit pyngrok

Step 2: Run Streamlit App
streamlit run app.py

Step 3: Use ngrok (for public access)
ngrok http 8501

Step 4: Copy the generated public URL and open in browser.
